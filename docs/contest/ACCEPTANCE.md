# Приёмка (РСХБ.Цифра 2026)

Критерии из ТЗ (PDF) — что должно быть готово к сдаче.

## Обязательный состав поставки

1. **Репозиторий** с README (запуск, env, ограничения) и ARCHITECTURE.
2. **Рабочий end-to-end**: загрузка фото → поиск → карточка JSON / UI.
3. **Mobile-first UI** в духе портала «Своё Вино».
4. **Скрипт оценки организатора** (`eval/participant_test.sh`) против endpoint  
   `POST .../eval/predict` → `{"slug":"..."}` (см. `architecture/API.md`).
5. **Метрики**: F1 / accuracy@1 / recall@5, latency p50/p95; цель SLA **&lt; 3 с** на eval-пути.
6. **Презентация ≤ 7 мин** (шаблон в `contest/`).
7. **Доп. функция после поиска** (аналоги / «сомелье» / retention) — см. UI и API.
