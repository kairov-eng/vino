# Техническое задание: «Сканер вина» / Своё Вино

Версия 1.1 · 2026-09-27 · Статус: реализация соответствует ТЗ (стек и API — фактические)

Исходная постановка: конкурс РСХБ.Цифра «Сканер российских вин…» (PDF).  
Данные — `DATA.md`, архитектура — `ARCHITECTURE.md`, этапы — `ROADMAP.md`, приёмка — `docs/contest/ACCEPTANCE.md`.

---

## 1. Цель

Веб-сервис: одна фотография этикетки/бутылки (полка, наклон, блики) → **одна** карточка из каталога «Своё Вино» в mobile-first UI.  
Если вина нет в каталоге — честный отказ и **аналоги**.

## 2. Критерии успеха (из постановки)

| № | Критерий | Цель | Вес |
|---|----------|------|-----|
| 1 | Точность top-1 на контрольной выборке | 90–100 % | 50 |
| 2 | Отрыв top-1 от top-2 (margin) | стабильный | в 1 |
| 3 | Функция после поиска | аналоги / retention | 20 |
| 4 | Архитектура, Docker, README | воспроизводимость | 15 |
| 5 | Дизайн «Своё Вино», mobile-first | — | 10 |
| 6 | Время ответа | ≤ 3 с (цель ниже) | 5 |

## 3. Границы

### 3.1 В объёме

- Каталог вин + медиа + embeddings (pgvector).
- Пайплайн: YOLO → embeddings → OCR → exclusive → XGB/CE → FinalScore.
- API: `POST /api/findwine`, `POST /v1/eval/predict`, каталог, история, настройки.
- UI: скан, карточка, «не найдено» + аналоги, история, admin-настройки.
- Eval-скрипт организатора без правок контракта.
- Деплой Docker (`vino_*`) на vino-svoe.online.

### 3.2 Вне объёма

- Нативные приложения.
- Полная онлайн-интеграция в Strapi портала (импорт из экспорта — да).
- Хранение секретов/медиа/больших весов в git.

## 4. Пользователи и сценарии

**П1 — Покупатель у полки.** Открывает сайт → фото → карточка (название, винодельня, регион, сорт, описание, фото) → аналоги.

**П2 — Вина нет в каталоге.** Сообщение + 3–5 аналогов с пояснением.

**П3 — Скрипт организатора.** `multipart image` → `{"slug":"..."}`; timeout 10 с; endpoint `/v1/eval/predict`.

**П4 — Разработчик.** Admin UI: настройки пайплайна, разбор `status`, история сканов, ручная привязка.

**П5 — Пополнение каталога.** Новый CSV/медиа → офлайн ingest/embed → дамп/rsync на сервер (не hot-reload Strapi).

## 5. Функциональные требования (привязка к реализации)

### 5.1 Данные и индекс

- ФТ-1.1 Импорт каталога → `wines` / `wineries` (~2103 slug).
- ФТ-1.2 Сопоставление фото: sitemap → photo_name → slug (`DATA.md` §4, `media.py`).
- ФТ-1.3 Кропы этикеток эталонов (`crop/`, `wines.crop`, `label` / `label_ocr`).
- ФТ-1.4 Embeddings SigLIP2 (+ DINOv3) в pgvector HNSW.
- ФТ-1.5 Поставка: `distrib/sql` + volumes media/models.

### 5.2 Распознавание

- ФТ-2.1 Приём JPEG/PNG/WEBP/HEIC; нормализация размера.
- ФТ-2.2 YOLO label / bottle+label; primary crop; foreign_mask.
- ФТ-2.3 SigLIP2 (± DINOv3); опц. reuse прошлого поиска.
- ФТ-2.4 OCR cascade (Rapid + Gemini/GV/… по настройкам).
- ФТ-2.5 Exclusive lexicon + ColorDelta + TextScore (fin1/fin2) + XGB + CE.
- ФТ-2.6 `matched_wine` / отказ; для eval — лучший slug.
- ФТ-2.7 Ответ: кандидаты, `status`, `algorithm_version`, URLs кропов.

### 5.3 UI и после поиска

- ФТ-3.1 Карточка вина из каталога + ссылка на портал при наличии slug.
- ФТ-3.2 Аналоги после match / not_found.
- ФТ-3.3 История сканов, ручное «соответствие».
- ФТ-3.4 Site password (admin/user).

### 5.4 Диагностика

- ФТ-4.1 Admin: настройки, разбор шагов в карточке скана.
- ФТ-4.2 Eval-скрипт + история для метрик.

## 6. Нефункциональные

| Категория | Требование |
|-----------|------------|
| Latency | p95 ≤ 3 с на eval-пути при разумных OCR-настройках |
| Надёжность | деградация при падении опц. OCR/CE; `/api/health` |
| Воспроизводимость | `distrib/docker-compose.yml` + README + dump |
| Совместимость | `participant_test.sh` → `/v1/eval/predict` |
| CPU | backend на CPU; GPU — в отдельных ML-сервисах / HF |
| Безопасность | секреты в `.env`; media в volume; gate на API |
| Диск | большие веса не в git / не в толстом CUDA-слое app |

## 7. Метрики

- accuracy@1 / F1@1 / recall@5 на размеченной выборке.
- margin FinalScore / cosine.
- latency по этапам в `status.timings_ms`.
- Публичный набор: `eval/queries`; приватный — у организаторов.

## 8. Риски (актуально)

| Риск | Митигирование |
|------|----------------|
| Near-duplicates | OCR + exclusive + XGB |
| Доменный разрыв студия↔полка | YOLO crop, multi-OCR, reuse |
| Медленные LLM OCR | таймауты, Rapid fallback, настройки |
| Мало места на VPS | slim prod image, ML снаружи, prune |
| Мало полевых фото | история сканов + training bundles |
