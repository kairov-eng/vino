### 2.1 Структура slug

Большинство slug'ов генерируются по шаблону
`{винодельня}-{название}-{сорт}-{цвет}-{сладость}-{крепость×10}[-{объём}]`, например
`fanagoriya-100-ottenkov-krasnogo-saperavi-krasnoe-suhoe-14`, `abrau-dyurso-brut-dor-blanc-de-noirs-pino-nuar-beloe-bryut-115`.
Из хвоста извлекаются атрибуты для реранкера: цвет (`beloe|krasnoe|rozovoe|oranzhevoe`), сладость (`suhoe|polusuhoe|polusladkoe|sladkoe|bryut|ekstra-bryut|zero-dosage`), крепость (`135` → 13,5), объём (`07`, `0375`). Часть slug'ов короткие (`sira`, `oleg`, `pobeda`) — атрибуты берём из колонок.

### 2.2 Near-duplicates (главный источник ошибок)

- 69 пар «одинаковое название + винодельня, разные slug» (152 вина). Отличия: сладость (`4 elements. Рислинг` сухое/полусухое), цвет (`Adagum Pinot Noir` розовое/красное), крепость (`Brut d'Or` 11,5/12,5), год/партия (`cantiani-riesling` vs `cantiani-riesling-1`).
- **14 фото используются двумя slug'ами одновременно** (например, `03-Silvaner-2022-Barrel-Fermented.webp` → `vibes-silvaner-barrel-fermented-2022` и `vibes-vermentino-viognier-barrel-fermented-2022`). Визуально их различить нельзя — только по OCR или это неустранимая неоднозначность. Такие группы фиксируются в таблице `wine_image_groups`.
- Серии с одинаковым дизайном и разным текстом: Массандра (Мускатель белый/розовый/чёрный), Фанагория «100/101 оттенков», Родное Гнездо «4 elements», Абрау-Дюрсо Victor Dravigny, Аристов Anima.

## 4. Правило сопоставления slug → файл фото

```
1. wines_sitemap_*.xml: <loc>https://vino-svoe.ru/wines/{slug}</loc> … <image:loc>…/uploads/{file}</image:loc>
   → 2033 / 2103 slug, все файлы присутствуют на диске.
2. Fallback по «Название фото»: translit(имя без расширения) → [^A-Za-z0-9]+ → '_' → lower;
   поиск оригинала ^{key}_[0-9a-f]{10}\.\w+$ (регистр игнорируем). При нескольких кандидатах — все в индекс.
   → ещё 61 slug.
3. data/manual_image_map.csv (ручные соответствия). Нерешённые (5): method-classic-kokur (DSC00836),
   kokur-suhoe-2025 (DSC00839-Photoroom), beloe-polusladkoe (base64-имя), ona-skazala-da и
   rozovoe-polusladkoe-2 (Generated Image June 22…).
```

Транслитерация Strapi (`nameToSlug`): `ц→cz, ч→ch, ш→sh, щ→shh, й→j, ю→yu, я→ya, ь/ъ→∅`. Пример: `Спуманте белый брют.webp` → `Spumante_belyj_bryut_d34e854a7b.webp`.

Итог: **2094 из 2103 вин (99,6 %)** получают эталонное фото; для 9 остаются только текстовые признаки.

## 6. Подготовка валидационного набора (задача команды)

Публичных полевых фото всего 3 — этого недостаточно для настройки порогов и весов. План:

1. Собственная съёмка: ≥ 150 фото ≥ 50 вин из каталога в магазинах (полка, наклон 0–30°, блики, разная дистанция), приоритет — near-duplicate серии из §2.2. Разметка slug в `data/val/queries.tsv` + `answers.tsv`.
2. Синтетика из эталонов: композиция бутылки на фон полки, перспектива, motion blur, блик, шум, кроп 60–100 % — 10 видов на вино для оценки recall и раннего отбора моделей (не заменяет реальные фото).
3. Обратная связь из UI (этап 3): подтверждённые/исправленные ответы попадают в `data/feedback/`.
