### 2.1 Структура slug

Частый шаблон: `{винодельня}-{название}-{сорт}-{цвет}-{сладость}-{крепость×10}[-объём]`.  
Из хвоста извлекаются цвет / сладость / крепость / объём; короткие slug — атрибуты из колонок CSV.

### 2.2 Near-duplicates

- Десятки пар «одно имя + винодельня, разные slug» (сладость, цвет, крепость, год).
- **14 фото** используются двумя slug сразу — визуально неразличимы, нужен OCR.
- Серии с общим дизайном: Массандра, Фанагория «оттенки», Родное Гнездо «4 elements», Абрау-Дюрсо и др.

## 4. Правило slug → файл фото

Реализовано одинаково в:

- `research/label_detect/2.crop_wines.py` (офлайн кропы);
- `backend/app/media.py` (URL для UI).

Порядок кандидатов имени:

1. `wines_sitemap.image_file`
2. `wines.photo_name`
3. `COALESCE(slug, photo_name)` как `image_file`

Сопоставление в **корне** `MEDIA_ROOT` (без подпапок):

- точное имя;
- stem с `-`→`_` и тем же расширением;
- вариант `stem_<10 hex>.ext` (Strapi-hash);
- пропускать `thumbnail_` / `small_` / …

Итог по каталогу: **≈2094–2080** вин с файлом на диске; остальные — только текст.

Кроп этикетки: `MEDIA_ROOT/crop/{basename}_crop.png`, где basename — `safe_result_basename` от slug/photo_name (как в crop_wines).
